# Screenshots

Place plugin screenshots in this directory. For WordPress.org plugin submission, screenshots should be named:

- `screenshot-1.png` - Abandoned Carts list view showing all tracked abandoned carts
- `screenshot-2.png` - Statistics dashboard with recovery rate and revenue metrics
- `screenshot-3.png` - Plugin settings page for configuring abandonment time and email options
- `screenshot-4.png` - Recovery email template customization in WooCommerce settings

**Recommended dimensions:** 1544x500 to 1544x1200 pixels (or similar aspect ratio)

**For WordPress.org submission:**
Screenshots should be placed in the `/assets/` directory of your SVN repository, not in the plugin zip file.
